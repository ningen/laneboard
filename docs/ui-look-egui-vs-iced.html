egui を選ぶとき

  • 「作業台 / デバッグ盤」感でよい
  • 実装を速く、配布を単純にしたい
  • ドラッグ看板は自前だが、密な情報表示は得意

iced を選ぶとき

  • もう少し普通のデスクトップアプリに見せたい
  • テーマ・余白を設計する余力がある
  • それでも Web 版ほどの見た目自由度はない
